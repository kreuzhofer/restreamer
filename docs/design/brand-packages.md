# Brand package surface

Mode: Operate. Extend the existing Studio Library styling and navigation.

The operator imports a curated kit once, reviews its contents, then creates an editable show using one of its content templates. The package page belongs under Library alongside Themes. Keep the established dark palette, compact controls, plain separated sections and inline feedback. Package identity and human-readable version lead each section; technical hashes stay out of the interface.

Desktop supports file selection, validation, import and show creation. Phones support package inspection and access to theme previews/downloads, preserving the established desktop-only authoring boundary. Removal first shows which items will be removed and which edited/referenced resources will remain.

Importing must not choose broadcast stages, change on-air media or adopt a newer theme in an existing show. Errors stay near the operation with a recovery action. Cancelling an in-flight import asks the user to refresh its status because publication may already have completed.

## First corporate kit

The user approved the light Möbius Nebius direction on 2026-11-11 after reviewing actual generated Starting soon, BRB and Ending videos and the transparent OBS border. The treatment uses official logo and motion assets, licensed Gramatika Bold, a white ground, deep blue text and restrained lime/lavender accents. Editable copy remains above the motion area. The complete source motion cycle is retimed to eight seconds at 1080p25; source audio is muted, leaving soundtrack selection to Studio.

Corporate assets, detailed internal provenance, the import ZIP and preview renders remain private and are not bundled in the repository or release image. The public sample builder uses original generic artwork and the bundled Go font.
