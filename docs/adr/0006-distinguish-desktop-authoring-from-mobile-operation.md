# Distinguish desktop authoring from mobile operation

The dashboard's growing set of broadcast, setup, and authoring controls makes a single stacked interface cumbersome. The redesign separates Live, Studio, and Settings, with desktop providing the full production workspace and mobile prioritizing broadcast operation, destination delivery controls, and prepared-media browsing, preview, and selection; text editing, uploads, regeneration, scene composition, theme editing, ingestion-key management, destination configuration, and streaming-profile changes require desktop in the initial version. This deliberately gives up complete phone feature parity to keep live controls usable and accessible.
