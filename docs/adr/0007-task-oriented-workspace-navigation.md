# Expose broadcast setup separately from the media library

The operator cannot reliably rediscover stage assignments among Studio's layered navigation and authoring controls. Use four primary destinations—Live, Show setup, Library and Settings—with a dedicated editor reached from setup or the library, accepting an additional primary destination to make preparation and resource management explicit. This supersedes only ADR 0006's Live/Studio/Settings navigation choice; its desktop-authoring/mobile-operation boundary remains in force.
